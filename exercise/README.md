## Time to Practice

Let's practice with some trees! Follow both of the exercises below to get a better understanding of binary trees and AVL trees.

### Exercise 1: Implementing a Binary Tree

Use the starter code in [this CodePen](https://codepen.io/GAmarketing/pen/jJOxBd) to take a stab at creating a binary tree, checking your work against the test script. There are several functions to implement; the `height` and `isBalanced` functions will probably be more difficult and you can consider them to be optional.

### Exercise 2: Implementing an AVL Tree

Let’s balance some trees! This [CodePen](https://codepen.io/GAmarketing/pen/bZGMaQ?editors=0010#0) has some pseudocode to get you started with implementing an AVL tree. This is a tricky exercise — get as far as you can and use the test scripts to check your work.

Remember:

- Fork the Pen before making any changes.
- Don’t make edits to the test script at the bottom.
